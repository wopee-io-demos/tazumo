# Initial marketplace foundation

## Why
The existing food-only proof of concept cannot yet support a robust cross-platform European multi-category launch.

## What changes
- Create Next.js + Expo Router pnpm monorepo.
- Share catalogue and brand packages; implement functional product discovery and local cart on all platforms.
- Add OpenSpec specs and ADRs, truthful demo disclosure and basic CI.
- Keep category, color and name modular.

## Impact
Provides a coherent engineering baseline and demonstrable UI. Excludes production backend, payments, courier dispatch, identity, and store distribution.
