# Changelog

Product releases of the Tazumo SUT (web, mobile and API together). Entries after 0.1.0 are generated by release-please from Conventional Commits; see [docs/RELEASING.md](docs/RELEASING.md). Contract versions are tracked separately and reported in each build's `version.json`.

## [0.1.0](https://github.com/wopee-io-demos/tazumo/releases/tag/v0.1.0) (2026-11-21)

Baseline: the state of `main` before automated releases, tagged once by hand. SUT contract 0.2.0, OpenAPI 0.7.0-draft. Synthetic demo data only; no real orders, payments or delivery.

### Features

* **web:** React/Vite marketplace with merchant discovery, search, product detail and cart line editing; disabled checkout ([#8](https://github.com/wopee-io-demos/tazumo/pull/8), [#50](https://github.com/wopee-io-demos/tazumo/pull/50))
* **web:** EN, CS and DE localisation with a header language switcher, per-route localised titles and a no-index policy ([#16](https://github.com/wopee-io-demos/tazumo/pull/16), [#81](https://github.com/wopee-io-demos/tazumo/pull/81), [#126](https://github.com/wopee-io-demos/tazumo/pull/126))
* **mobile:** Expo React Native app with native product detail and cart screens ([#45](https://github.com/wopee-io-demos/tazumo/pull/45))
* **sut:** canonical SUT contract v0.2.0 for web and native automation ([#90](https://github.com/wopee-io-demos/tazumo/pull/90))
* **api:** PostgreSQL-backed catalogue, bearer JWT authentication with roles, rate limits, admin role grants, GDPR erasure and export, order quotes ([#49](https://github.com/wopee-io-demos/tazumo/pull/49), [#62](https://github.com/wopee-io-demos/tazumo/pull/62), [#66](https://github.com/wopee-io-demos/tazumo/pull/66), [#72](https://github.com/wopee-io-demos/tazumo/pull/72), [#129](https://github.com/wopee-io-demos/tazumo/pull/129), [#133](https://github.com/wopee-io-demos/tazumo/pull/133))
* **commerce:** market, VAT and synthetic fee rules with a transparent price breakdown ([#80](https://github.com/wopee-io-demos/tazumo/pull/80))
* **address:** market address validation and a geocoder port ([#107](https://github.com/wopee-io-demos/tazumo/pull/107))
* **backoffice:** role-gated back-office console foundation ([#106](https://github.com/wopee-io-demos/tazumo/pull/106))
* **idp:** local Keycloak realm with Mailpit password reset ([#145](https://github.com/wopee-io-demos/tazumo/pull/145))
* **payments:** Stripe test-mode adapter with webhook verification ([#151](https://github.com/wopee-io-demos/tazumo/pull/151))
* **pages:** public web preview on GitHub Pages with a live smoke ([#150](https://github.com/wopee-io-demos/tazumo/pull/150))
