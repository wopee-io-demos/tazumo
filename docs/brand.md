# Provisional brand design brief

Status: candidate only, pending trademark/domain/native-speaker clearance.

## Shortlist and risk
- Tazumo: selected working name, not legally cleared. Preliminary search surfaced unrelated name uses.
- Zupomi: backup with sparse exact-name web footprint, not legally cleared.
- Zopiku: elevated similarity concern with ZOPIK grocery delivery in India and other Zopik uses, not automatically a European trademark bar.
For real rollout search EUIPO TMview, WIPO, national registrations, marketplace classes (9/35/39/42 and potentially 43), domains and pronunciation tests; obtain qualified legal counsel.

## Identity
- Warm, clever, trustworthy and modern. Avoid generic glossy 3D mascot and overdecorated checkout.
- Fox mascot is a **design direction**, not an owned final asset. Use no unlicensed character artwork. The 🦊 emoji is only a temporary placeholder.
- Primary wordmark: bespoke design target. Current text logotype is a placeholder.
- Fonts: Plus Jakarta Sans for candidate identity; system font fallback currently used until licensed/hosted font is integrated.
- Voice: approachable, concise, transparent about fees and ETAs. “Good things are closer” is provisional messaging.

## Palettes, independent from naming
The user can change palette independently of name and mascot. Tokens are centralized in packages/brand. Candidate directions: coral, violet, emerald, blue, midnight lime and pink. Product interface uses neutral high-contrast surfaces with vivid accents. Verify WCAG 2.2 AA for each token pairing; no claim of certification is made.

## Visual quality gates
Test recognizable icon at 24/48/128px, real photography, color independence, accessibility, packaging, courier apparel, localization and consumer research across EU languages. Avoid asserting speed or availability without live operational evidence.
